# pair-wise-yy-62 多用途船舶配载方案校核与航次审阅平台

支持集装箱、散货和重大件配载，提供三维货位查看、二维剖面、拖拽换位、重心与稳性计算、危险品隔离、绑扎冲突、方案对比和可打印配载图。

## 技术栈

React、Mantine、Redux Toolkit、React Router、RTK Query、Three.js、Vite、TypeScript。

## 运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62062`。方案草稿保存在浏览器本地状态。

```bash
npm run build
```

## 离线草稿合并（船 / 码头对账）

离港前船端与码头各持一份配载草稿，网络恢复后在「离线合并对账」页导入对端审阅包：

- **审阅包**：JSON 格式，携带方案版本、共同基线版本、基线集合指纹、每票货位与绑扎指纹及角色限制条件；导入前先验航次、基线版本和指纹，不一致直接拒绝。
- **逐票三方合并**：以共同基线为祖先，按提单合并；只有一边改的字段直接收，两边改成相同值静默通过，两边改成不同值（同一提单）或两票被移到同一货位时保留两版并列出冲突，不再后导入覆盖。
- **锁定守卫**：冲突未全部处理不能锁定；货位冲突在后续编辑中解除会自动关闭，新产生的挤占会补登。
- **限制条件复核**：限制接受时记录相关货位指纹，合并或编辑导致货位指纹变化后自动转为「需重新确认」，重新确认前不能锁定。
- **失败可重试**：导入解析或对账失败时原草稿、既有冲突原样保留，可用同一审阅包重试或改选文件。

页面上的「生成码头端演示包」可基于当前基线构造一份含提单冲突、货位挤占、单边自动合并与限制失效场景的审阅包，用于体验完整流程。
